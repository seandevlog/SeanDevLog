## ⭐ Featured Project

### Inventory Tracker — Complete ✅ / Actively Expanding 🚀

A full-stack inventory management system built with **React, Express, Node.js, and MongoDB**, focused on structured data, CRUD workflows, authentication, and maintainable backend logic.

**Core Features:**

- Inventory item tracking with CRUD workflows
- JWT authentication
- Role-based access control
- REST API and database integration
- Cloudinary image upload integration
- Frontend deployed on Vercel
- Backend deployed on Render
- Clean UI for managing products, stock, and operational records

**Currently Expanding With:**

- New features and workflow improvements
- Better UI/UX
- Testing and maintainability improvements
- Cleaner backend structure
- Documentation and screenshots

📌 Live Demo: [Inventory Tracker](https://inventory-tracker-mu-roan.vercel.app)
